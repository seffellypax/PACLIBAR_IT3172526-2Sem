# Career Launcher – Project Planning Board

## Overview
**Career Launcher** is a project proposal focused on helping users manage and track career opportunities such as job applications, application statuses, notifications, and user account management.  

This repository contains the **project planning board** created using GitHub Projects. The board organizes the development workflow into multiple sprints to ensure structured and efficient project management.

## Project Planner
The planning board includes:
- Sprint planning
- Task management
- Feature tracking
- Bug fixing
- Security improvements
- User interface updates
- Deployment preparation

The project follows an agile-style workflow with tasks divided into weekly sprints.


# Purpose of the Project
The goal of **Career Launcher** is to provide users with a centralized platform for organizing and managing their career application process efficiently. The project focuses on improving productivity, application tracking, and user experience.
